# VFR Atelier · نسخهٔ سوم

[اتاق پرو V3](https://prestigegitserp.github.io/VFR_base/v3/) · [نسخهٔ ۲](https://prestigegitserp.github.io/VFR_base/v2/) · [نسخهٔ ۱](https://prestigegitserp.github.io/VFR_base/v1/) · [پروتکل اسکن، تن‌خور و فروش](docs/PROTOCOL_FA.md)

سه قاب مستقل صورت، بالاتنه و تمام‌قد با دو ورودی دوربین و عکس و یک مانکن تعاملی. شش لباس و دو فریم اپتیک با هندسهٔ سه‌بعدی، اندازه‌های میلی‌متری به تفکیک SKU و رندرهای بازتولیدپذیر Cycles.

- در دوربین و عکس، اتصال لباس از خط شانه، دهانهٔ یقه، برش‌های قفسهٔ سینه و کمر و موقعیت آرنج و مچ استفاده می‌کند.
- پوشش مجازی تا لبهٔ نرم سیلوئت محدود می‌شود. پیراهن زیر کتِ مانکن در پرو دوربین حذف می‌شود و پوست گردن، مو و دست در نقاط هم‌پوشان دیده می‌شوند.
- بالاتنه با لگن خارج قاب کار می‌کند. برای صورت قاب مستقل فریم عینک و برای تمام‌قد دامنهٔ حرکت لباس‌های بلند در دسترس است.
- کنترل دستی جابه‌جایی، عرض و طول برای هر قاب مستقل است. «ثابت‌کردن فریم» عکس همان لحظه را برای تنظیم محلی نگه می‌دارد و دوربین را می‌بندد.
- پنل عیب‌یابی وضعیت نقاط مرجع، تازگی ماسک، زاویه و زمان تشخیص را نشان می‌دهد. خروجی JSON شامل تصویر، نقاط خام یا اندازه‌های بدن نیست.
- بستهٔ لباس سه‌بعدی، مدل کالیبرهٔ GLB هر سایز را از ZIP می‌خواند. یک بستهٔ نمونهٔ دو سایزی و خروجی پیش‌نویس سفارش در سایت موجودند.

## ساخت

```bash
npm ci
npm run stage:models
npm test
npm run dev
npm run build
```

دوربین به HTTPS یا localhost و دسترسی مرورگر نیاز دارد. WebGL2 رندر سه‌بعدی را اجرا می‌کند. ردیاب، GPU و سپس CPU را امتحان می‌کند. در دستگاه‌های سازگار، تحلیل فریم در Web Worker اجرا می‌شود. مدل‌ها و WASM از همان انتشار GitHub Pages خوانده می‌شوند.

## بازتولید دارایی‌ها

```bash
python tools/prepare-forms.py
node tools/export-looks.mjs
blender -b --factory-startup -noaudio --python-exit-code 1 --python tools/render-looks.py -- --samples 42
python tools/pack-renders.py
node tools/sample-package.mjs
```

ابزار آماده‌سازی فرم به NumPy و تبدیل تصویر به Pillow نیاز دارد. مدل پایه و تارگت‌های MakeHuman با مجوز CC0 به فرم مرجع تطبیق داده شده‌اند. [مجوزها و منشأ دارایی‌ها](public/notices/README.txt)
