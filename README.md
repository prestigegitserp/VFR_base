# VFR Atelier · نسخهٔ ششم

[اتاق پرو V6](https://prestigegitserp.github.io/VFR_base/v6/) · [نسخهٔ ۴](https://prestigegitserp.github.io/VFR_base/v4/) · [پروتکل](docs/PROTOCOL_FA.md)

## فیت سه‌بعدی

- دوربین و عکس از نقاط ژست و سیلوئت یک مش مثلثی بدن می‌سازند. بازوها، گردن و لگن به تنه متصل‌اند. مش در حالت تمام‌قد تا پاها امتداد دارد. هنگام پوشیدگی اندام، حرکت آن با قید طول استخوان و برآورد ژست کامل می‌شود.
- در «ساخت مش و اندازه» قد را وارد کن و «اسکن دو نما» را بزن. دوربین از روبه‌رو و نیم‌رخ چند فریم می‌گیرد و پهنا و عمق را در ده مقطع تنه تخمین می‌زند. فرم ثبت‌شده در ژست‌های دیگر ثابت می‌ماند. اندازه‌های مترخورده هم می‌توانند ابعاد مش را تنظیم کنند.
- مش هر لباس الگوی پایهٔ سایز و پارچهٔ خودش را دارد. حل‌گر XPBD کشش یال، خم‌شدن، حرکت و تماس با مثلث‌های مشِ بدن را در رأس و داخل سطح هر تکه در نظر می‌گیرد. نواحی یقه، سرشانه و سرآستین با وزن‌های متفاوت مهار می‌شوند. یقه، زیپ و جیب از سطح تغییرشکل‌یافته نمونه‌برداری می‌شوند.
- «نمای سه‌بعدی» آخرین ژست معتبر را برای چرخش نگه می‌دارد. در آن می‌توان تن‌خور، مش بدن یا نقشهٔ کشش یال‌ها را دید و مش بدن را در قالب OBJ گرفت. رنگ‌ها نسبت طول یال‌ها به الگوی پایه را نشان می‌دهند.
- GLB ایستا تا سقف محاسبات فریم با سطح بدن فیت می‌شود. مدل با قطعات آستین نام‌گذاری‌شده از حرکت بازو هم پیروی می‌کند. GLB سنگین یا دارای پوست و اسکلت سفارشی با نقاط مرجع تراز می‌شود. فیت عینک با عمق مش صورت انجام می‌شود.

از یک تصویر، عمق و شکل بخش‌های پوشیده تخمین زده می‌شود. اسکن دونما با لباس نزدیک به بدن اطلاعات بیشتری دارد. طول و کشش از کاتالوگ و پارامترهای تقریبی پارچه می‌آیند. نمایش هماهنگ سرعت تازه‌سازی متناسب با سرعت ردیابی دارد. دوربین و اسکن روی دستگاه پردازش می‌شوند.

## مرجع روش‌ها

- جداسازی مش بدن و لباس و استفاده از شواهد سیلوئت. [DeClotH، CVPR 2025](https://arxiv.org/abs/2503.19373)
- استفاده از قید ژست همراه با قرینهٔ سطح برای بدن نیمه‌پوشیده. [PromptHMR، CVPR 2025](https://openaccess.thecvf.com/content/CVPR2025/html/Wang_PromptHMR_Promptable_Human_Mesh_Recovery_CVPR_2025_paper.html)
- مدل‌سازی لباس با قیود اندازه و تماسِ قابل حل. [DiffAvatar، CVPR 2024](https://openaccess.thecvf.com/content/CVPR2024/html/Li_DiffAvatar_Simulation-Ready_Garment_Optimization_with_Differentiable_Simulation_CVPR_2024_paper.html) · [ContourCraft، SIGGRAPH 2024](https://arxiv.org/abs/2405.09522) · [XPBD، MIG 2016](https://doi.org/10.1145/2994258.2994272)

نسخهٔ مرورگری از این ایده‌ها با مش پارامتری، گراف قید مثلث‌ها و حل‌گر محلی استفاده می‌کند. وزن‌های آموزشی مدل‌های پژوهشی جزو برنامه نیستند.

## ساخت و آزمون

```bash
npm ci
npm run stage:models
npm test
npm run dev
npm run build
```

دوربین به HTTPS یا localhost و رندر تعاملی به WebGL2 نیاز دارد. آزمون‌ها بسته‌بودن مش، اثر نمای نیم‌رخ، تماس پارچه و بدن، تفاوت الگوی سایزها و پایداری فریم عینک را می‌سنجند. آزمون مرورگر با عکس عمومی و دوربین آزمایشی، خروجی OBJ و تغییر نمای سه‌بعدی را هم بررسی می‌کند.
