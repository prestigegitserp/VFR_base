# VFR Atelier · نسخهٔ دوم

[اتاق پرو V2](https://prestigegitserp.github.io/VFR_base/v2/) · [نسخهٔ ۱](https://prestigegitserp.github.io/VFR_base/v1/) · [پروتکل اسکن، تن‌خور و فروش](docs/PROTOCOL_FA.md)

سه قاب مستقل صورت، بالاتنه و تمام‌قد با دو ورودی دوربین و عکس و یک مانکن تعاملی. شش لباس و دو فریم اپتیک با هندسهٔ سه‌بعدی، اندازه‌های میلی‌متری به تفکیک SKU و رندرهای بازتولیدپذیر Cycles.

- تمام‌قد، لبهٔ آزاد و حرکت پارچهٔ بارانی، پیراهن و دامن را نمایش می‌دهد.
- بالاتنه برای شروع پرو فقط شانه‌ها را لازم دارد. اگر نقاط اصلی کم‌اطمینان باشند، از چهره و سیلوئت برای برآورد بالاتنه استفاده می‌شود.
- صورت، فریم را به دو چشم و محور چهره می‌بندد و چرخش سر را دنبال می‌کند.
- فرم مانکن، بر اساس یکی از پنج فرم مرجع یا ابعاد آزاد کاربر تغییر می‌کند.
- پارامترهای تن‌خور به‌ازای هر کالا و ابعاد تعریف شده‌اند. جدول، اندازهٔ پوشاک و اختلافش با بدن را نمایش می‌دهد.
- بستهٔ لباس سه‌بعدی، مدل کالیبرهٔ GLB هر سایز را از ZIP می‌خواند. یک بستهٔ نمونهٔ دو سایزی داخل سایت است.
- پیش‌نویس سفارش، سایز، رنگ و SKU را خروجی می‌دهد. کالای واردشده می‌تواند آدرس HTTPS خرید فروشنده را داشته باشد.

## ساخت

```bash
npm ci
npm run stage:models
npm test
npm run dev
npm run build
```

دوربین به HTTPS یا localhost و دسترسی مرورگر نیاز دارد. WebGL2 رندر سه‌بعدی را اجرا می‌کند. ردیاب، GPU و سپس CPU را امتحان می‌کند. در دستگاه‌های سازگار، تحلیل فریم در Web Worker اجرا می‌شود. مدل‌ها و WASM از همان انتشار GitHub Pages خوانده می‌شوند.

## بازتولید دارایی‌ها

```bash
python tools/prepare-forms.py
node tools/export-looks.mjs
blender -b --factory-startup -noaudio --python-exit-code 1 --python tools/render-looks.py -- --samples 42
python tools/pack-renders.py
node tools/sample-package.mjs
```

ابزار آماده‌سازی فرم به NumPy و تبدیل تصویر به Pillow نیاز دارد. مدل پایه و تارگت‌های MakeHuman با مجوز CC0 به فرم مرجع تطبیق داده شده‌اند. [مجوزها و منشأ دارایی‌ها](public/notices/README.txt)
