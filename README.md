# VFR Studio · اتاق پرو مجازی

[نسخهٔ آنلاین](https://vfr-fitting-studio.ardent-slug-5662.chatgpt.site) · [طراحی فنی و بررسی رقبا](docs/ENGINEERING_FA.md) · [نمونهٔ قالب](docs/garment-template.json)

پرو زندهٔ لباس با یک وب‌کم RGB معمولی. مدل تشخیص حالت بدن، آینه و رندر سه‌بعدی روی دستگاه بازدیدکننده اجرا می‌شوند. هشت لباس اولیه شامل پیراهن تک‌شانه و بنددار، دامن پلیسه، کت زنانه و مردانه، بامبر، بارانی و هودی‌اند. هر لباس سه رنگ و پنج سایز دارد. پیش‌نمایش کاتالوگ با Blender Cycles از همان هندسه‌ای تولید شده که در آینه حرکت می‌کند.

## استفاده

- **استودیو** با مانکن متحرک، باد، نمای نیم‌تنه و کنترل مقایسه. بدون دسترسی دوربین می‌توان لباس‌ها را امتحان کرد.
- **دوربین زنده** با ردیابی شانه، لگن، آرنج و مچ. نیم‌تنه برای کت و هودی کفایت می‌کند. برای پیراهن و دامن، پاها را هم در قاب بگذار تا برخورد تقریبی پایین لباس فعال شود. در تنظیمات می‌توان نمای آینه‌ای، نمایش اسکلت و تعویض لباس با دست را فعال کرد.
- **عکس من** با ورودی محلی و همان موتور رندر. عکس روبه‌رو و با نور یکنواخت نتیجهٔ بهتری می‌دهد.
- **اندازه‌گذاری** با مقایسهٔ ابعاد بدن و اندازهٔ خود لباس در پنج سایز. اندازه‌های دوربینی با قد معلوم، سیلوئت بدن و چند فریم معتبر برآورد می‌شوند. اندازهٔ مترخورده برای انتخاب سایز واقعی مناسب‌تر است.
- **قالب لباس** از میان هشت الگوی هندسی موجود، جنس و رنگ و اندازه‌های خود لباس را می‌گیرد. قالب JSON را می‌توان وارد و خارج کرد و روی همان مانکن، عکس یا دوربین دید.
- **ثبت عکس** تصویر آینه را PNG ذخیره می‌کند. عکس و ویدئو به سرور ارسال نمی‌شوند. قالب و اندازه‌ها در حافظهٔ محلی همین مرورگر می‌مانند.

## ساخت و اجرا

```bash
npm ci
npm test
npm run stage:models
npm run dev
npm run build
```

اجرای دوربین در مرورگر به HTTPS یا localhost و اجازهٔ دوربین نیاز دارد. حالت سه‌بعدی با WebGL2 اجرا می‌شود. MediaPipe ابتدا GPU و سپس CPU را امتحان می‌کند. مرحلهٔ `stage:models` فایل مدل و WASM را کنار سایت می‌گذارد تا هنگام استفاده درخواست به CDN لازم نباشد. اجرای توسعه بدون این مرحله از URLهای ثابت MediaPipe استفاده می‌کند. برای بازتولید بدون شبکه، فایل‌های مدل و WASM همین مرحله را همراه خروجی `dist/` نگه دارید.

### GitHub Pages

گردش‌کار [Pages](.github/workflows/pages.yml) شاخهٔ `v1` را آزمایش و بسته‌بندی می‌کند. برای انتشار روی دامنهٔ GitHub از Settings → Pages، منبع را روی **GitHub Actions** قرار دهید. در مخزن عمومی فعلی، دامنهٔ Pages پس از فعال‌سازی مستقل از پیش‌نمایش آنلاین بالا می‌آید.

### بازتولید رندرها

```bash
node tools/export-look-meshes.mjs
blender -b --factory-startup -noaudio --python-exit-code 1 --python tools/render-looks.py -- --samples 48
python tools/pack-renders.py
```

فایل‌های میانی در `.render/` ساخته می‌شوند. Python برای بسته‌بندی WebP به Pillow نیاز دارد. اطلاعیه‌های [وابستگی‌ها](public/notices/) همراه پروژه‌اند.
