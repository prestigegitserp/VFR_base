# VFR Atelier · نسخهٔ چهارم

[اتاق پرو V4](https://prestigegitserp.github.io/VFR_base/v4/) · [نسخهٔ ۳](https://prestigegitserp.github.io/VFR_base/v3/) · [پروتکل پرو و اسکن](docs/PROTOCOL_FA.md)

- عکس و دوربین با پروجکشن پرسپکتیو، حجم تخمینی تنه را از نقاط ژست و لبه‌های سیلوئت می‌سازند. برشِ نزدیکِ بالاتنه با اطلاعات صورت و سطح شانه تکمیل می‌شود.
- در لباس‌های داخلی، پوستهٔ سه‌بعدی دور سینه، کمر و بازو ساخته می‌شود. حلقهٔ آستین و تنه رئوس مشترک دارند. قیدهای برخورد و حرکت ثانویهٔ لبه، پارچه را هنگام خم‌شدن عضو یا حرکت پایین لباس تنظیم می‌کنند.
- برای عینک، نقاط ثابت پل بینی، گوشه‌های چشم و کناره‌های صورت با یک مدل پرسپکتیو تطبیق داده می‌شوند. مش صورت در عمق رندر قرار می‌گیرد تا دستهٔ دورتر با چرخش سر پشت صورت برود.
- نمای سه‌بعدی آخرین فریم معتبر را برای چرخش و بررسی از کنار نگه می‌دارد. تنظیم عمق، زاویهٔ لنز، عرض، طول و جابه‌جایی تصویر هم در دسترس است.
- رندر و ثبت گزارش فنی روی دستگاه انجام می‌شوند. گزارش، شاخص‌های فنی مثل سرعت، کیفیت شانه و خطای بازفرافکنیِ مدل را صادر می‌کند.
- بسته‌های GLB قبلی، پروفایل اندازه و پیش‌نویس سفارش قابل استفاده‌اند. مش GLB ثابت با نقاط مرجع سه‌بعدی تراز می‌شود و شکل ثبت‌شدهٔ آستین را حفظ می‌کند.

## ساخت و آزمون

```bash
npm ci
npm run stage:models
npm test
npm run dev
npm run build
```

دوربین با HTTPS یا localhost و رندر زنده با WebGL2 اجرا می‌شود. پردازش تصویر در مرورگر به MediaPipe و WebAssembly متکی است. کار با دوربین RGB پرسپکتیو، ژست و تماس را تخمین می‌زند. فرم و افت لباس با عمق و خواص اندازه‌گیری‌شده دقت بیشتری پیدا می‌کند.

آزمون پرسپکتیو، چرخش سر و استقلال فریم عینک از نگاه را با ورودی کنترل‌شده می‌سنجد. آزمون مرورگر از عکس عمومی MediaPipe، برش نزدیک بالاتنه و جریان ویدئوی آزمایشی استفاده می‌کند.
